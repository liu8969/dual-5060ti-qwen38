# 换 DDR4 服务器平台研判（为 STRATA / 本地大模型）

调研日期 2026-10-03 · 结论已量化，**所有外推数字都标了依据** · 相关：`docs/STRATA-FLASH-NEXT.md`

## 0. 先纠正一个前提

**不是"DDR4 把 PCIe 压到 4.0×8"，是 5060 Ti 本身就只有 x8 条 lane。**

本机 `lspci -vv` 实测（192.168.0.119）：

```
LnkCap: Speed 32GT/s, Width x16
LnkSta: Speed 32GT/s, Width x8 (downgraded)      # 两张卡都是这样
```

所以**在任何平台上每张卡最多用 x8**，一代平台给一代链路：

| 平台代际 | 每卡链路 | 单向带宽（理论 / 实测估） |
|---|---|---|
| 现在：Raptor Lake + DDR5 | **PCIe 5.0 x8** | 32 / ~26 GB/s |
| Ice Lake-SP、EPYC 7002/7003（DDR4） | **PCIe 4.0 x8** | 16 / ~13 GB/s |
| Skylake/Cascade Lake、E5 v3/v4（DDR4） | **PCIe 3.0 x8** | 7.9 / ~6.5 GB/s |

结论：搬到 DDR4 平台，**每卡 PCIe 一定掉到 1/2（4.0）或 1/4（3.0）**，没有例外（DDR4 平台没有 PCIe 5.0）。

## 2. 带宽到底卡在哪一步（STRATA 的三条腿）

STRATA 每个 token 的专家权重流量 = `层数 × top-k × 单专家字节`，24,576 专家、每 token 激活几百个专家切片，
按 IQ2_XS（~2.4 bit）估 **每 token 数百 MB 量级**。这些字节走哪条腿，决定了谁是真瓶颈：

| 阶段 | 瓶颈在哪 | 本机状况 |
|---|---|---|
| **预填（prompt）** | 流式区间里每个 chunk 都要**重流每一层的专家**（ExTV 实测：加大 chunk 直接把 80K 预填从 510→1,451 tok/s）。所以预填 ∝ **PCIe 带宽**；RAM 不够时先是 **SSD 换页**主导 | 31 GB RAM → 卡在换页档（ExTV 同档 350–1,796 横跳、上千万次 major fault） |
| **解码（decode）** | VRAM 专家缓存命中率 → 没命中的在 **CPU 上用 RAM 带宽**原地算。VRAM 越小越吃内存带宽（官方 5070 12 GB 上 79 tok/s ≈ 该机内存带宽的量级） | 32 GB VRAM 命中率不低，**部分**受内存带宽限制 |
| **长上下文** | KV 流式 / 会话 parking 全在 RAM（~13.7 KB/上下文 token，262K ≈ 3.5 GB） | 31 GB 完全不够 |

一句话：**预填看 PCIe 和 SSD，解码看 VRAM 命中率 + 内存带宽，长上下文看容量。** 三者要分开算账。

## 3. 平台对照（外推，低置信，仅供选型排序）

假设：STRATA + IQ2_XS/Q2_0，2×5060 Ti，除第一行外内存都 ≥128 GB（即已摆脱换页档）。

| 平台 | 内存实测带宽（估） | 每卡 PCIe | 32K 预填（估） | 解码（估） | 现役 vLLM TP=2 |
|---|---|---:|---:|---:|---|
| **现状**：DDR5-4800 2ch / 32 GB | **49**（实测） | Gen5 x8 | 350–1,200（换页主导） | 50–90 | all-reduce 16.5%（实测） |
| 现状 + 4×32 GB DDR5 = 128 GB | ~49–60 | Gen5 x8 | **2,000–2,600** | 60–100 | 不变，**不动显卡最优解** |
| Ice Lake-SP 8ch DDR4-3200 / 256 GB | 140–160 | Gen4 x8 | 1,000–1,300 | 80–120 | all-reduce ~2×→ 解码 −15~20% |
| EPYC 7002/7003 8ch DDR4-3200 / 256 GB | 140–160 | Gen4 x8 | 1,000–1,300 | 70–110 | 同上 |
| Cascade/Skylake-SP 6ch DDR4-2933 / 192 GB | 95–105 | Gen3 x8 | 500–650 | 80–120 | all-reduce ~4×→ 解码 −25~40% |
| E5 v3/v4 4ch DDR4-2400 / 128 GB | ~50 | Gen3 x8 | 500–650 | 50–80 | 明显回退 + 功耗噪音 |

预填外推标定方式：官方 5070（Gen5 x16，~50 GB/s 实测）在 32K 上 2,090–2,650 tok/s，按"每 chunk 全层专家重流"反推
每 2K chunk 约 20–25 GB 专家流量，误差约 ±2×；用于比较**平台之间**的倍数关系是可靠的。

**读法**：搬到 DDR4 平台，预填是"先靠 128 GB 内存摆脱换页（+3~5×）、再被 PCIe 砍（4.0 −2× / 3.0 −4×）"，
4.0 平台净赚 ~1.5–2.5×，3.0 平台基本持平甚至倒退。**内存是第一优先，PCIe 代际是第二优先。**

## 4. 更大的内存值不值

| 内存 | 能做什么 | 边际收益 |
|---|---|---|
| **31 GB（现在）** | 只能 mapped/换页档，major fault 与 swap 决定速度 | 官方症状三条（慢/磁盘灯常亮/引擎被 OOM 杀）全中 |
| **64 GB** | 官方"每个尺寸都放得下"的门槛（IQ3_S 要少开别的程序）；仍要盯着 RAM | 摆脱 SSD 主导，预填 3–5× |
| **128 GB** | 舒服档：全驻留 + KV 流式 + 会话 parking + page cache；**能上 IQ3_XXS/IQ3_S（质量更好）**、262K 上下文 | 速度边际递减，**质量档位**上一个台阶 |
| **256 GB** | 唯一能整块吃下 Unsloth **UD-Q4_K_XL（111 GB，最接近全精度）**的容量档 —— 官方在 64 GB 机器上只有 7–8.5 tok/s（全在 SSD 上爬），全驻留后完全是另一个东西 | 这是"大内存换质量"唯一的硬路径 |
| >256 GB | 单模型无收益 | 只为多模型/多会话/别的服务 |

结论：**64 GB 是及格线，128 GB 是舒服线，256 GB 是"上 4-bit 大模型"的门票**；
超过模型体积 + 20 GB 之后再多的内存只买安全垫，不买速度。

## 5. 洋垃圾采购清单（按"对 STRATA 的适配度"排序）

> 价格为二手行情量级，**以你当地（闲鱼/华强北/eBay）现货为准**；DDR4 已停产，2025 年起 EOL 反而推高 RECC 价格，
> 别按"电子垃圾白菜价"预期。

### 方案 A（首推）：单路 Ice Lake-SP，8 通道 DDR4 + AVX-512 + PCIe 4.0
- CPU：Xeon Gold **5318Y**(24C/165W) / **5320**(26C) / **6330**(28C) / Silver **4314**(16C，最便宜)
- 板：**Supermicro X12SPi-TF**（单路 ATX、PCIe 4.0 x16 槽）/ X12SPL-F / ASUS Z12PA-U12
- 内存：**8×32 GB DDR4-3200 RECC = 256 GB**（必须 8 条全插满才有 204 GB/s）
- 优点：唯一同时具备 **AVX-512(VNNI) + 8 通道 + PCIe 4.0** 的 DDR4 平台；解码腿最强
- 缺点：Ice Lake-SP 的 AVX-512 重载会降频；平台本体比 Purley 贵

### 方案 B（大 L3 路线）：EPYC 7002/7003 Rome/Milan，8 通道 + 128 lane PCIe 4.0
- CPU：**7F52**（16C/3.5 GHz/**256 MB L3**，对"反复读热点专家"很对味）/ 7402 / 7532 / 7B13；
  Milan-X 的 7573X/7773X 有 **768 MB L3**，能把一大块热点专家留在片内（溢价买它）
- 板：**H12SSL-i**（注意：H11SSL 是 PCIe **3.0**）/ ROMED8-2T
- 内存：8×32 GB DDR4-3200 RECC = 256 GB
- 优点：PCIe 4.0 128 lane（两卡各 x8 专享、CPU 直连）、带宽与 A 同级、L3 巨大
- 缺点：**没有 AVX-512**（Zen2/Zen3 只有 AVX2）；默认 NPS4 是 4 个 NUMA 节点，**BIOS 里改 NPS1**，否则 STRATA 这种非 NUMA 感知的程序会吃亏

### 方案 C（便宜大碗，但预填被 PCIe 封顶）：Purley 单路 Skylake/Cascade Lake
- CPU：Gold **6132**(14C/2.6) / **6138**(20C/2.0) / **6248**(20C/2.5) / Platinum 8260
- 板：X11SPi-TF / X11SPL-F
- 内存：6×32 GB DDR4-2933 = 192 GB（6 通道 140 GB/s）
- 优点：最便宜的大内存 + AVX-512（Cascade Lake 起带 VNNI）
- 缺点：**PCIe 3.0 x8 = 每卡 7.9 GB/s**，预填天花板 ~500–650 tok/s（约现在的 1/4）；只适合"以对话/解码为主、少喂长文档"

### 不推荐
- **E5 v3/v4（Haswell/Broadwell-EP）**：4 通道 DDR4-2133/2400（理论 68/77 GB/s ≈ 我们现在的 DDR5 双通道，**带宽零收益**）、只有 AVX2、PCIe 3.0、整机 idle 200 W+、噪音大。除了"128 GB 只要几百块"没有优点。
- **双路**：STRATA 不感知 NUMA，双路只会给你半个 CPU 的内存带宽 + 更差的延迟 + 双倍功耗噪音。**单路 + 插满所有通道**永远优先。
- **1U/2U 准系统**：40 mm 风扇起飞，除非有独立机房。
- 显卡别插 PCH/芯片组挂的槽，要插 **CPU 直连**的 x16 槽。

### 方案 0（不换平台，最省钱，可能才是最优）
现板 **4×32 GB DDR5 = 128 GB**（板子上限 128 GB）。代价：2DPC 可能从 4800 降到 3600–4000，带宽维持 ~50 GB/s；
但**保住了 Gen5 x8 的 PCIe 天花板，也完全不动现役 vLLM**。以 STRATA 的角度，这一档拿到的正是"摆脱换页"的最大那块收益
（预填 350→2,000+），丢掉的是 AVX-512 和多通道带宽（只影响解码那条腿，估 20–40%）。

### 如果你能接受 DDR5（附注）
Zen4/Zen5（7950X/9950X + B650/X670）**同时有 AVX-512 和 PCIe 5.0 x8**，128–192 GB DDR5 也不算小，
是"三条腿都不瘸"的唯一消费级路线；拦路的是 2025 年以来的内存行情。若 DDR5 比 DDR4 RECC 还贵才轮到 Xeon。

## 6. 对现役 vLLM 的连带影响（最容易忽略的一笔）

现役 `vllm-dflash` 是 **TP=2**，我们自己的测量里 all-reduce 占 step 时间 **16.5%**（Gen5 x8 = 32 GB/s）。
搬去 DDR4 平台后（链路减半/减到 1/4），all-reduce 占比会明显变大，**这不依赖 STRATA，是确定的损失**：

- Gen4 x8（16 GB/s）：all-reduce 约翻倍 → 解码掉 **15–20%**（292 tok/s → 240 上下）
- Gen3 x8（7.9 GB/s）：更糟，可能掉 **25–40%**

所以：**如果新平台的目的是给现役 27B 生产扩容，不要搬显卡**；如果目的是跑 STRATA / 125B，那这笔回退要算进预算。

## 7. 买之前先做三个"不花钱"的实验（在本机 31 GB 上就能做）

1. **建基线**：现在跑一次 STRATA（IQ2_XS，ctx 131072），记录 `strata-*.log` 的 prefill/decode 计时行 +
   `pgmajfault` / `pswpin` / NVMe 读取量（照 ExTV `tools/snapshot.py` 的思路）。这就是"31 GB 换页档"的锚点。
2. **量化 PCIe 的敏感度**：同一提示，对比引擎参数
   - `--pcie-frac 0`（没命中的专家全在 CPU 算 ≈ 模拟"链路很慢"）
   - 默认（链路快时把没命中的专家拉过 PCIe 交给 GPU 算）
   两者的解码差距 = **PCIe 减半/减到 1/4 时你会亏多少**。差值小 → 方案 C（Gen3）也能买；差值大 → 只能上 4.0 平台。
3. **量化内存的收益**：用 `--resident-budget-gib N` 模拟不同 RAM 预算（把预算调小 ≈ 今天的 31 GB，调大 ≈ 128 GB），
   看预填从"换页档"爬到"PCIe 档"能涨多少倍。这直接验证第 3 节外推的 +3~5×。

跑完这三步再下单，比现在盲买一台 Xeon 稳。要我按这个流程在本机跑一遍（会停 vLLM 腾卡），说一声即可。
